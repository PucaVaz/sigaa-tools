A carga horária de extensão e a de componentes flexíveis contam para a
integralização do curso, e o comprovante de cada participação é uma declaração
ou um certificado emitido pelo SIGAA. Esta consulta lista as suas participações
em ações de extensão e diz, para cada uma, quais documentos o SIGAA oferece
agora, sem abrir o portal. Ela é **somente leitura**: não emite nem baixa
nenhum documento.

Os dados vêm da página **Certificados e Declarações** do Portal do Discente
(Documentos autenticados de Extensão), consultada ao vivo. **Networked.**

## Consultar pelo CLI

```bash
sigaa extensao
sigaa extensao --json
```

A saída legível agrupa as participações por tipo. Exemplo com dados fictícios:

```text
Team member (2)
  2099 - PROJETO IMAGINÁRIO – ROBÓTICA EDUCACIONAL
    DISCENTE | ALUNO(A) BOLSISTA | 01/02/2099 – 31/12/2099
    documents: declaração
  2097 - OFICINA HIPOTÉTICA DE DADOS ABERTOS
    DISCENTE | MONITOR(A) | 05/05/2097 – 05/11/2097
    documents: certificado

Audience (1)
  PJ000-2096 - Curso Fictício de Programação para a Comunidade
    DISCENTE (UFPB) | PARTICIPANTE | registered 20/06/2096 | frequency 75%
    documents: none available yet

Summary: 1 declaration(s) and 1 certificate(s) available
```

| Flag | Descrição |
|---|---|
| `--json` | retorna o contrato JSON normalizado, também exposto pelo MCP |

## Consultar pelo MCP

A tool `sigaa_list_extension_participations` não recebe parâmetros e retorna o
mesmo contrato de `sigaa extensao --json`. Como é somente leitura, ela continua
disponível com `SIGAA_MODE=hosted`.

## Contrato JSON

```json
{
  "participations": [
    {
      "kind": "team_member",
      "title": "OFICINA HIPOTÉTICA DE DADOS ABERTOS",
      "action_code": null,
      "year": 2097,
      "category": "DISCENTE",
      "role": "MONITOR(A)",
      "start_date": "05/05/2097",
      "end_date": "05/11/2097",
      "registered_on": null,
      "frequency": null,
      "status": null,
      "declaration_available": false,
      "certificate_available": true,
      "sigaa_id": "900003"
    }
  ],
  "counts": {
    "team_member": 1,
    "audience": 0,
    "extension_student": 0,
    "declarations_available": 0,
    "certificates_available": 1
  }
}
```

| Campo | Origem no SIGAA |
|---|---|
| `kind` | tabela: `team_member` (membro de equipe organizadora), `audience` (público alvo) ou `extension_student` (discente de extensão) |
| `title`, `action_code`, `year` | cabeçalho da ação: `<ano> - <título>` ou `<código> - <título>`; o ano vem do sufixo do código quando não há ano explícito |
| `category` | coluna Categoria (equipe e público alvo) |
| `role` | Função (equipe), Participação (público alvo) ou Vínculo (discente) |
| `start_date`, `end_date` | Início e Fim, em `DD/MM/AAAA` |
| `registered_on`, `frequency` | Data do Cadastro e Frequência (público alvo) |
| `status` | Situação (discente), por exemplo `ATIVO` |
| `declaration_available`, `certificate_available` | o ícone Emitir Declaração / Emitir Certificado está presente na linha |
| `sigaa_id` | id interno do registro: `idMembro`, `idCadastroParticipante` ou `idDiscenteExtensao` |

O nome do estudante, repetido em todas as linhas da página, não é retornado.

## Quando um documento aparece

As regras são as que o próprio SIGAA informa na página:

- A **declaração** pode ser emitida a qualquer momento enquanto o membro da
  equipe está ativo na ação.
- O **certificado** só é liberado quando a participação do membro da equipe é
  finalizada.
- Para quem participa como **discente de extensão**, o certificado só é
  liberado depois do envio do Relatório Final.

Uma participação encerrada com `certificate_available: false` normalmente
significa que o certificado ainda não foi liberado pela coordenação da ação.

## Erros

Uma página que não é reconhecida como a lista de documentos de extensão, uma
tabela desconhecida ou colunas que mudaram de nome geram um erro de etapa
`parse` (CLI sai com código 1; MCP retorna erro de tool). A lista vazia só é
retornada quando a página é reconhecida e não mostra nenhuma ação de extensão.

## Inscrever-se em uma seleção

Para entrar em uma ação de extensão como discente, o SIGAA pede que você se
registre como interessado na seleção da ação: Portal do Discente →
**Inscrever-se em Seleção de Projeto de Ensino** → tipo de bolsa **Extensão** →
ícone **Participar da Seleção** → **Registrar-se como Interessado**. O comando
`sigaa selecao-extensao` e duas tools MCP fazem esse caminho.

Esta é a única operação da ferramenta, além da matrícula on-line, que **escreve
no SIGAA**. Ela acontece em três passos, e só o último envia algo:

```bash
# 1. achar a oportunidade (somente leitura, lento: o SIGAA lista o ano inteiro)
sigaa selecao-extensao --search "trilha ufpb"

# 2. abrir o formulário e conferir a ação (nada é enviado)
sigaa selecao-extensao --apply 16743

# 3. registrar o interesse
sigaa selecao-extensao --apply 16743 \
  --qualifications "Experiência em programação e monitoria..." --confirm
```

```text
  16743 open    1 paid  CI-DCC       TRILHA – UFPB: FORMAÇÃO TÉCNICA, MENTORIA E PROTAGONISMO ESTUDANTIL EM COMPUTAÇÃO - Etapa 2026-2027
1 of 1133 opportunities
```

O campo **Qualificações** é obrigatório no SIGAA e é lido pela coordenação da
ação; o **Currículo Lattes** (`--lattes`) é opcional.

### Pelo MCP

| Tool | O que faz |
|---|---|
| `sigaa_search_extension_opportunities(query, year?)` | busca somente leitura; `query` é obrigatório porque o SIGAA lista todas as ações do ano |
| `sigaa_apply_extension_selection(opportunity_id, qualifications, lattes_url?, year?, confirm=false)` | com `confirm=false` só mostra a ação (`status: "preview"`); com `confirm=true` registra o interesse |

Um agente só deve chamar `confirm=true` quando o estudante pediu aquela ação
específica e escreveu ou aprovou o texto de qualificações. As duas tools não
gravam arquivos e continuam disponíveis com `SIGAA_MODE=hosted`.

### Resposta

```json
{
  "action": {
    "opportunity_id": "16743",
    "title": "TRILHA – UFPB: FORMAÇÃO TÉCNICA, MENTORIA E PROTAGONISMO ESTUDANTIL EM COMPUTAÇÃO - Etapa 2026-2027",
    "action_code": "PJ823-2026",
    "coordinator": "TATIANA ARAUJO SIMOES",
    "kind": "PROJETO",
    "unit": "CI - DEPARTAMENTO DE COMPUTAÇÃO CIENTÍFICA",
    "funding": "FINANCIAMENTO INTERNO (EDITAL PROEX No 16/2026 - PROBEX 2026-2027)"
  },
  "submitted": true,
  "status": "registered",
  "messages": ["Operação realizada com sucesso. E-mail de confirmação enviado para: [e-mail]"]
}
```

| `status` | Significado |
|---|---|
| `preview` | o formulário foi aberto e nada foi enviado |
| `registered` | o SIGAA respondeu com o alerta de sucesso |
| `rejected` | o SIGAA respondeu com um erro ou aviso; `messages` traz o texto |
| `unconfirmed` | o SIGAA respondeu sem sucesso nem erro: confira em **Visualizar Resultados das inscrições** antes de assumir qualquer coisa |

O e-mail e o telefone do estudante, exibidos no formulário, nunca são lidos, e
endereços de e-mail nas mensagens do SIGAA são mascarados como `[e-mail]`.

O SIGAA da UFPB decodifica formulários em Windows-1252. O texto de
qualificações é enviado nessa codificação; caracteres que ela não representa
(emojis, por exemplo) são recusados antes de qualquer envio, em vez de chegarem
corrompidos à coordenação.

Abrir o formulário de uma ação em que você já está inscrito falha com a
mensagem do próprio SIGAA ("Você já realizou a inscrição para esta ação de
extensão"), o que também serve para conferir uma inscrição feita.

A lista de oportunidades só é considerada vazia quando o SIGAA diz "Nenhuma
oportunidade foi encontrada". Uma oportunidade sem o ícone de seleção aparece
com `can_apply: false` e não pode ser aberta.

## Fora do escopo

- Emitir ou baixar declarações e certificados.
- Eventos de `watch` para novas participações ou documentos liberados.
- Cancelar uma inscrição ou consultar o resultado da seleção.
- Seleções de monitoria, pesquisa, apoio técnico e ações associadas.
